# Basic Properties

> [!abstract] 정의 (위상군)
>
> $G$가 group임과 동시에 topological space이며, $-\cdot-:(x,y)\to xy$와 $(-)^{-1}:x\mapsto x^{-1}$이 모두 continuous map일 시 $G$를 **topological group**이라고 한다.
